## 2. 结论：多摆放对精度提升 ≈ 0

- 单摆放标定 RMS ≈ **0.0298mm**；5 摆放联合后 0.0295mm；LOO 0.0297mm。
- 提升只有 **0.3µm 量级**，可以认为没有实质收益。
- 原因：每摆放的刚体（旋转/平移）已被 SVD 配准剔除；剩下的残差是**同一块标定板**的
  "板子自身误差 + 模型残差"，它在 5 个摆放里是**同一个固定场**，多摆放无法把它分开/消掉。
  （5 个摆放的配准残差 RMS 都是 0.0296–0.0390mm，量级一致，正说明残差与摆放无关。）

## 3. 评估"虚拟角点 ×1/×2"

- **不增加任何新信息**：虚拟角点是在 266 个已测点之间插值出来的，等价于把拟合模型算密，
  交叉验证/LOO 不会因此改善。
- 即使把 5 个摆放的 1330 个**真实**角点全部用上，实测也只有 0.3µm 提升（见上）；
  虚拟点不可能比真实点多出信息。
- 把控制网格从 13×13 翻倍到 25×25 也不可行：1330 点 ÷ 625 节点 ≈ 2 点/节点，必然过拟合
  （此前 5×5/7×7 分区交叉验证已崩到 1.7~119mm）。

**所以"5 图 + 虚拟角点翻倍"不能带来有意义的精度提升，不推荐实施。**

## 4. 那什么才有效（结论不变）

提升的瓶颈是**标定板本身**（打印/蚀刻误差、特征类型）和**模型表达**，不是摆放次数：
1. 换**玻璃/光刻标定板**（板子误差 0.01–0.05mm → 可忽略，一次扫描即可）；
2. 用**十字图案标定板**（软件已支持 `pattern="cross"`），让标定特征与测量特征一致，
   消掉"角点 vs 十字"的 0.005–0.015mm 特征差；
3. **更密标定图案**（更多真实角点）+ 更细分区的模型（需配套交叉验证）；
4. 固定扫描窗口、统一条件、重复扫描平均（降随机项）；
5. 多摆放残差层可作为"系统残差记录"保留（LOO 0.03mm），但它不是你追求精度提升的关键手段。
