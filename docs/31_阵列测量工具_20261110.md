# 新工具：十字阵列测量 `tools/array_measure.py`（2026-11-10）

> 目的：把"测一张阵列图"变成一条命令，输出间距/旋转/阵列自身残差，
> 便于 14 以后快速判断"这张纸/这次打标行不行"，也用于回归验证。

## 1. 用法

```bat
python tools\array_measure.py IMAGE.jpg
python tools\array_measure.py IMAGE.jpg --json out.json
python tools\array_measure.py IMAGE.jpg --pitch-mm 30.0
```

输出示例（0003）：

```
2026-10-22-0003.jpg: 5x5  n=25
  行步=30.0741mm 列步=30.0157mm 旋转=-0.397deg
  阵列残差 RMS=0.0626mm Max=0.1518mm
```

## 2. 算法

1. `auto_detect_chessboard(pattern="cross")` 自动识别十字阵列（行列、间距、中心）；
2. 以自动中心为种子，生产检测器 `detect_points`（寻边法）精测每个十字中心；
3. 检测点按最近邻对回自动中心（处理 rematch 乱序），按行/列聚类编号；
4. 对 (行,列)→像素坐标做仿射拟合（吸收旋转/平移/尺度），残差 = 阵列自身不规整度；
5. 任何一步失败都**明确报错、不输出假数据**（红线 2）。

## 4. 用途建议

- 新样件到手先跑一遍：残差 ≤0.1mm 可用；>0.2mm 说明阵列/打标本身有问题；
- 同一张纸重复扫描各跑一遍，比较间距/残差 → 判断放置/扫描重复性；
- 作为"换纸/换打标参数"的快速判据，避免拿歪纸去做振镜校正。
