## 3. 结论与建议

1. **金标样件换成 2026-10-14-0013**（0.0467mm），比 0003（0.0626mm）更好；
   建议把 0013 固定保存、不弯折、固定方向，作为以后回归验证的基准。
2. 0009/0010/0011 这批（1.15–1.26mm）**不要用于校正**——纸/打标本身歪到 1mm 级，
   拿它们校正会把阵列误差当扫描仪误差学进去。
3. 0006（0.69mm）也只能做"检测器压力测试"，不能当基准。
4. 0008/0012/10-15 是不同行列数（6×6/5×6/3×4），自动识别点数不全，需要手动指定行列后单独测。
5. 0007 暴露了"带旋转十字阵列自动识别失败"的弱点，后续值得单独修（与检测器鲁棒性同一条线）。
