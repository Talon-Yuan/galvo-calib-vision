## 2. 典型案例复盘

### 案例 A：B-15 文件对话框无限递归（"按钮坏了"）

- **现象**：点「导入扫描图」「导入棋盘格图像」毫无反应；日志里出现 `RecursionError: maximum recursion depth exceeded` 且同一行重复 994 次。
- **根因**：为让对话框跟随深色主题，我用脚本把三份 GUI 文件里的 `QFileDialog.getOpenFileName(` 全局替换成自定义 shim `qfd_open(`。shim 自身内部也写了 `return qfd_open(...)`，于是自调用成环。
- **修法**：shim 体内改回 `QFileDialog.getOpenFileName/getSaveFileName/getExistingDirectory`（3 个文件 × 3 类 = 9 处）。
- **验证**：桩替换 `QFileDialog` 后三模块 `qfd_open` 均正常透传；真实导入流程 `src loaded=True`（0.1s）。
- **教训**：批量文本替换后必须检查"被替换目标是否也出现在替换产物里"；对函数包装尤其要用精确匹配。

### 案例 B：B-09/B-10 样式表整表被丢弃（"改了像没改"）

- **现象**：改了 QSS 但界面几乎没变化；风格部分生效、部分回到系统默认。
- **根因两层**：
  1. `QSpinBox, QDoubleSpinBox { qproperty-alignment: AlignRight | AlignVCenter; }` —— QFlags 属性裸写，Qt 解析失败；
  2. 深色样式由脚本转换生成，转换器用 `名字: 值` 正则扫全表，把选择器里的 `QToolButton::hover` 改成 `QToolButton: hover`，整表非法。
  两者都会让 Qt **丢弃整张样式表**（只留警告），表现为"某些地方怎么都不跟着变"。
- **修法**：QFlags 加单引号；转换器只处理 `{}` 内声明区。
- **验证**：`qInstallMessageHandler` 捕获 `Could not parse application stylesheet`，在**真实 MainWindow 存在**时逐块 setStyleSheet 校验，138 条规则 0 坏块。
- **教训**：QSS 校验必须"带真实控件"做，否则解析延迟、测不出来。

### 案例 C：B-22 反复切主题后回不到浅色

- **现象**：深色 → 浅色切换若干次后，界面停在中性灰/黑色，必须重启。
- **根因**：浅色分支用 `app.style().standardPalette()` 取调色板。该函数在**已应用样式表**的 QApplication 上返回 Window=#000000 的异常调色板，页面被刷黑。
- **修法**：浅色也显式构造 QPalette（Window #eef1f6 / Base #ffffff / Text #1f2d3d …）。
- **验证**：连切 3 轮，`app.palette().Window` 交替为 #eef1f6 / #0f1319；所有控件 WindowText 同步。
- **教训**：样式表与调色板是两套机制，不能互相推导；关键状态必须显式给定。
