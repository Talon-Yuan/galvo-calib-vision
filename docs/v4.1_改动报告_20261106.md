## 2. 本版改动（已实施）

### A. 建系只定位，不再定义阵列
- 自动建系只求「阵列中心 + 旋转」；行列以界面参数为准。
- 检测窗按**实测间距**铺（窗口跟住真实十字，边缘不漂移）——这是必要工程妥协；
- 名义值/图上名义网格按**设计间距**（两者解耦）。

### B. 阵列可选（参数为权威）
- 阵列页：预设下拉 + 自定义行列（已有控件，全部生效）；
- 自动检测的行列与参数不一致 → 弹窗选「按界面参数 / 按检测」（默认参数）；
- 新增「按参数铺网格」：不点选也能铺网格（`应用阵列（下一步）` 兜底）；
  - 已点原点 → 用该点 + 参数；
  - 完全不点 → 图像中心 + 图像轴（日志/状态栏明确提示这是快速模式）。

### C. 名义网格显示
- 预览工具条新增「名义网格」开关（默认开）；
- 用**设计间距**、以网格原点+方向轴生成细线（虚线），偏差一眼可见。

### D. 网格自动校正改为"只提示一次"
- 不再自动改写网格、不再自动多轮重测；
- 实测偏差超阈值时：日志 + 状态栏提示一次（实测间距/间距偏差/预计边缘偏差），
  并把建议存 `_grid_correction_suggestion`，供报表留痕。

### E. 首次检测看门狗 8s → 30s
- 首次检测需解码原始灰度（2.23Gpx 可达数十秒），旧 8s 必误杀；
  已预热过（之前检测/建系解码过）仍用 8s 兜底。

### F. 同步项
- 工程保存/加载：行列/间距/DPI/阵列来源/实测间距；
- Excel 参数记录：阵列来源、实测阵列间距、间距偏差%；

## 4. 关于"自动建系到底还有没有意义"

- 有：它只做**位姿定位**（阵列在图像里的中心与旋转），相当于"找到阵列在哪"；
- 名义坐标永远由**设计参数**（数量/间距/中心原点）生成，不参与拟合；
- 若你希望完全不跑图像检测，可用「按参数铺网格」+ 点一下原点，效果等价（方向取图像轴）。
