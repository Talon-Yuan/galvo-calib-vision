## 1. R1 看门狗未回收（最重）

**现象**：超时"放弃等待"后 `_detect_guard` 未 stop、线程 progress 未断；
后台线程真正进入检测阶段时，进度回调会把**同一个单例 timer** 重新武装
→ 线程完成后约 20s 必弹假"检测失败"；用户若在这 20s 内重试，
旧 timer 会把**新检测**判超时并丢弃结果。

**修法**
- 放弃时：`guard.stop()` + `th.progress.disconnect()` + `self._detect_abandoned = True`
  + 禁用检测入口（btn_detect/btn_manual/btn_pick_next/btn_save_measure）+ 进度条复位
- `finished`：停表、清 `_detect_abandoned`、清线程引用、恢复全部按钮
- 起检测前：若 `_detect_thread.isRunning()` → 提示"后台仍在解码，请稍后重试"，拒绝重入
- 迟到的 done/error：`_detect_abandoned` 时直接丢弃
