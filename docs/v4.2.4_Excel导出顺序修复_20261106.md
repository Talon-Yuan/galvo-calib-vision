# v4.2.4 Excel 导出顺序修复报告（2026-11-06）

> 来源：用户反馈 `桌面\5-33.xlsx` 输出顺序不对。定位为 Sheet1 的"P 编号顺序"
> 与"名义值索引顺序"不一致，属真实缺陷（非显示格式问题）。

## 1. 复现

用户文件（3×3 / 设计间距 50mm，编号模式 `bottom_left_row_major`）Sheet1：

| Sheet1 | 名义值 | 实测值 | 实际对应点 |
|---|---|---|---|
| P3 | (-50, **+50**) | (-55.40, **-56.78**) | 名义取左上、实测取左下（错位） |
| P4 | (0, +50) | (-0.05, -56.06) | 名义取上排中、实测取左下中 |
| P5 | (+50, +50) | (55.01, -56.54) | 同理 |

Sheet2 的 序号 为 7,8,9,4,5,6,1,2,3（行主序位置 + 左下起编号），与 Sheet1 的
P3.. 顺序（1,2,3...）也不一致，两张表读起来对不上。

## 2. 根因

`core/excel_exporter.py::build_point_rows`：
```python
disp = display_order(rows, cols, order)     # 按编号模式取检测点
for i, rank in enumerate(disp):
    r = results[rank]                        # 检测结果按 rank
    fixed = nominal_points[i + 1]            # ← 名义值却按显示序号 i（错）
```
当编号模式不是"左上起行主序"（默认是左下起行主序）时，`rank != i`，
名义值与实测值来自不同点 → 表现为"顺序不对/名义和实测对不上"。

## 3. 修复

1. `fixed = nominal_points[rank + 1]`（含 P1 情形）/ `nominal_points[rank]`（不含 P1）
   —— 名义值始终与 `results[rank]` 同源；
2. Sheet2 数据行按**编号升序**输出（行/列列仍为真实位置），与 Sheet1 的 P3..P(n) 同序；
3. Sheet2 失败点清单同样按编号顺序；着色行号随排序改为写入顺序（修掉排序后填错行）；
4. Sheet2 序号改回 `display_no(rank, ...)`（排序后不再用旧下标）。

- Sheet2 行序 = 编号 1..N 升序
=> 全 PASS。

P4 (0,-50) 配 (-0.05,-56.06) ✓，P5 (50,-50) 配 (55.01,-56.54) ✓。
