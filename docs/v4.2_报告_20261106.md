## 1. 辅助建系（14 提的流程）

**用户操作**：点一下阵列中心附近的十字 → 软件在原始灰度上局部扫描、亚像素精测该十字
→ 用四邻域估计行列方向 → 按参数（行列数/设计间距/DPI）直接建设计坐标系 → 一键检测。

**实现**
- `CenterProbeThread`（QThread，不碰 UI）：
  1. `refine_manual_point` 三级窗口放大精测（clamp(0.25·pitch_px, 81, 1200) → 0.5 → 0.75）
  2. 四邻域 `detect_points` 探测；方向优先"邻居对"，单侧邻居用"邻居−锚点"（角点场景）
  3. 中心：奇×奇=锚点；任一维偶数=邻居中点；邻居不足=±半格并告警
  4. 返回 中心/方向/邻居数/实测间距/告警标志
- `_make_grid_from_center(center, xdir, ydir, origin_kind)`：唯一换算入口，
  中心→row0col0 角点按 `(n−1)/2·pitch·轴` 换算；返回 `GridDefinition`
- 点选模式下拉（`cb_pick_mode`）：单点中心（默认）/单点角点/两点·中心+X/三点传统
- 远点保护：精测锚点离点击 >1×间距、或邻居 <2（无第二点时）→ 明示"附近未找到十字"，不建假网格
- 探针成功：`origin_xy`=精测中心、`_array_source="center_probe"`、`_gray_warm=True`

## 2. NG 判定与坐标轴（语义变更）

**旧**：实测值先减"实测拟合阵列中心"再投影 → 整板平移被吸收，NG 判不出平移。
**新**：
```
实测 mm = _to_mm(det.x, det.y)
判定原点 mm = _to_mm(origin_px)          # 精测中心 或 用户点角点
(a, b) = (mm.x − o.x, −(mm.y − o.y))     # 物理 Y 向上为正
名义 = 设计偏移沿建系轴 × pitch，再 Y 取反（只用设计参数，不反推）
dx, dy = a − tx, b − ty
NG = |dx| > tol_x or |dy| > tol_y        # 默认 ±0.05mm，模板可覆盖
```
- 名义值改为"沿轴投影"生成（`core/grid_definition.nominal_points_mm`），因此**与轴朝向解耦**：
  行方向朝上/朝下、阵列旋转都自洽；`origin_kind="center"` 时 (0,0) 在中心，`"corner"` 时在起始角点。
- 表内 Y/ΔY 符号与 v4.1 相反（向上为正）；整板平移会真实反映为同号偏差。
- Excel 列名/列结构不变（红线 9），仅数值语义变化；参数页新增"判定原点/坐标轴"。
