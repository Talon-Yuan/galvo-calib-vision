# v4.3.11 整图痕迹导出包含识别过程

14 要求：导出扫描图 / 整图标记时，把识别过程也保留出来。

## 实现

导出整图痕迹图（`traces_full.png`）时，同目录自动生成 `<文件名>_识别过程/`：

- `p1.png … pN.png`：彩色识别过程（红=边沿点、绿实线=边缘线、绿虚线=中线、蓝=交点、黄=质心）；
- `识别过程记录.csv`；
- `识别过程.log`：逐点 method/置信度/交点/边沿点数 + 方法统计 + 质心兜底点数。

失败不影响整图痕迹本身，只写日志提示。单点 PNG 仍 ≤720px。
