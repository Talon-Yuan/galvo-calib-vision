# v4.3.13 高密度棋盘格支持（修复导入识别失败）

## 问题
路径 `D:\微信data\...\2026-10-21-0001\2026-10-21-0001.jpg` 的棋盘格导入后自动识别失败：
`检测到 41×137 / 55×108 个候选行列（超出允许 60×80）`。

## 根因
这张是**高密度小格子棋盘格**：真实内角点 **93×63**（94×64 格，单格 ≈566.7px = **3.00mm**）。
自动识别硬上限 max_rows=60 / max_cols=80，行列数超限被拒。

## 修复
- `auto_detect_chessboard` 默认上限 60×80 → **400×400**。
- 界面行列输入范围同步放宽到 400（标定面板 + 主界面）。
- 未改识别算法与标定算法。

## 验证（真实图）

| 路径 | 结果 |
|---|---|
| core 自动识别 | ok，93×63，单格 566.71px，1.5s |
| core 标定（分区 3×3） | ok，5859 角点，RMS **0.0439mm**，Max **0.1587mm**，11.8s |
| GUI（CalibrationWidget 真实按钮/线程） | 载入→自动识别(93×63)→单格 3.0→标定 ok（5859 点、RMS 0.0439mm）→保存 npz 成功 |
| 回归 | v43_ui_test / export_order / selfcheck PASS；门1/2/3 PASS |

## 使用注意
- 自动识别只给行列，不给物理尺寸；识别出 93×63 后把“单格 mm”改成实测值（本板 **3.0mm**）。
- 若沿用默认 10mm，尺度会整体放大 3.33 倍。
