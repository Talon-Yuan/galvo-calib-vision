# v4.3.14 方向以网格实测轴为准（修 0.5° 歪）

## 问题
0013 完整 GUI 流程导出的上传坐标，相对 CLI 黄金坐标整体旋转 **−0.5002°**（直接差 mean 0.49mm），
而自动建系得到的网格 X 轴角是 **0.0°**。方向歪，振镜校正会放大成系统性旋转误差。

## 根因
- `deskew`（摆正角）由预览图 Hough 估角：该图估出 **−0.5°**，实际阵列≈0°。
- 估角在后台线程完成后才写入 `_deskew_ang`，可能在检测/导出**中途**生效，静默旋转坐标。

## 修复
- 建系（自动建系 / 中心探测 / 手动建系）完成后，用**网格实测 X 轴角**设置摆正角；
- `_deskew_from_grid` 锁存后，忽略迟到的预览估角；
- 新图加载时重置该锁存。

## 验证（0013 完整 GUI 复跑）

| 指标 | 修前 | 修后 |
|---|---|---|
| 上传 vs 黄金 旋转差 | −0.5002° | **−0.0001°** |
| 直接差 mean / max | 0.49 / 0.74mm | **0.021 / 0.033mm** |
| 刚体对齐 RMS | 0.0228mm | 0.0227mm |

其余不变：25/25 检测、阵列残差 0.0448→0.0386mm、Sheet2 序号1=行5/列1、中心=(0,0)。
