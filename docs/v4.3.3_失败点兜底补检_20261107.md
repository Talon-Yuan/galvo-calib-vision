# v4.3.3 失败点兜底补检（审计闭环）

> 背景：GUI 检测对 0006/0008 只稳定检出 3/9、8/9。先按"局部质心精化"实现兜底，
> 独立复核（core-algo《19_兜底补检复核_20261107.md》）判定**不安全**：
> `refine_manual_point` 永不返回 None → 会制造假点（红线 2），且 win=1200 时误差达 20px/0.106mm。
> 据此重写为"局部 ROI 完整检测"方案，并实测验证。

## 1. 最终方案

1. 主检测 `detect_points_fast` 后，收集已检出的好点；
2. 用好点拟合"网格理论点 → 实际像素"的 2D 仿射，预测失败点位置；
3. 在预测点附近裁 **0.2×间距的大 ROI**（只含目标十字、不切掉长臂），
   跑完整 `detect_cross_in_roi`（十字形状校验 + 置信度门）；
4. 只有"检测 ok"且"离预测点 ≤ max(40, 0.1×pitch)"才接受；
   否则保留 `DETECT_FAIL`（绝不造点）。

## 3. 安全性

- 不再使用 `refine_manual_point`（它对空白也返回坐标）；
- 兜底走的是与主检测相同的十字校验+置信度门；
- 接受条件含距离上限，避免补到邻点；ROI 只含一个十字；
- 失败保持 DETECT_FAIL（红线 2：失败必须如实上报）。
