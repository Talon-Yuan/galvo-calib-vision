## 1. 新增：识别过程可视化

检测结果新增 debug 几何：四臂参与拟合的像素、四臂中线、交点、像素质心、是否回退均值。

菜单 **工具 → 导出识别过程（彩色）**，选目录后自动导出：
- `p1.png … pN.png`：每点 ROI 放大图
  - **红色** = 寻边/臂像素（参与直线拟合的点）
  - **绿色** = 四臂中线（拟合直线）
  - **蓝色十字** = 交点（最终中心）
  - **黄色小点** = 像素质心（用于对比"交点 vs 质心"是否偏移）
- `识别过程记录.csv`：逐点 method/置信度/交点坐标/质心差/拟合vs均值差/回退标记
- `识别过程.log`：逐点明细 + 方法统计

检测完成后的主日志也新增：`检测方法统计：edge_center+subpix=N, edge_center=M；拟合回退均值=K`。

命令行同功能：
```
python tools/export_debug_process.py IMAGE.jpg --out 输出目录
```

## 2. 修复：中心锚点优先"寻边中线交点"

`CenterProbeThread` 原来用 `refine_manual_point`（迭代对称窗口**质心**）找锚点，原点会偏。
现在：
1. 优先 `detect_points` 的 **edge_center**（寻边中线交点）检测；
2. 只有寻边失败才回退质心，并在日志明确写：
   `中心锚点方法=centroid_fallback` + 警告"原点可能偏移，请在识别过程中核对"。
