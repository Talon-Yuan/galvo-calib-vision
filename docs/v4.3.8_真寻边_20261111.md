# v4.3.8 真寻边：边缘线→中线→交点

14 指出的问题：p13 绿线不贴十字边缘、中心箭头标注污染拟合、中点可能找偏。

## 改法

1. 水平臂逐列取上/下**边沿点**；竖直臂逐行取左/右**边沿点**（不是臂内部像素）。
2. 按厚度中位数剔箭头/加粗畸变；去两端各 10%（箭头标注区）。
3. 拟合四条**边缘线**；成对平均得两条**中线**（穿过箭头区延伸）；两中线求交点。
4. 拟合失败才质心兜底 `centroid_fallback`（留痕）。
5. 识别过程图：绿实线=四条边缘线（贴边）、绿虚线=两条中线、红=边沿点、蓝=交点、黄=质心。
6. 监督审计 P1 同步修：`local_retry` 保留内层 method/debug（`local_retry:centroid_fallback` 不再洗白）；
   导出图限 720px（原 25 张 800MB+）；统计改数质心兜底；中心锚点强制 edge_center。
