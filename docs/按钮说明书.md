# GalvoCalibVision 按钮说明书（v4.0 / 2026-10-27）

> 说明每个按钮/菜单项**在哪、什么时候可用、点了会做什么、有什么坑**。
> 文末附自动导出的全量控件清单（59 项，由运行中的程序枚举，非手写）。

## 1. 使用原则

1. 按钮**灰掉不是坏了**：多数是前置条件未满足（最常见：未完成棋盘格标定）。
2. 主操作为蓝色实心（导入/自动识别/一键检测/应用阵列/拟合与校验/导出 Excel），其余为白底描边。
3. 危险操作（清除手动点等）为红字红框，需二次确认。
4. 折叠行以 `>` / `v` 开头：`>` 收起、`v` 展开。

## 2. 顶部流程条（4 个胶囊）

| 按钮 | 行为 | 何时可用 |
|---|---|---|
| ① 标定棋盘格 | 切到标定页 | 始终 |
| ② 导入相纸扫描图 | 切到阵列页 **并直接弹导入** | 始终（建议先完成标定） |
| ③ 定义阵列与建系 | 切到阵列页 | 始终 |
| ④ 检测与导出 | 切到检测导出页 | 始终 |

当前步骤为蓝底，已完成为绿底；下方提示「当前步骤高亮，点任一步可直接跳转」。

## 3. 标定页（① 标定棋盘格）

| 按钮 | 行为 | 前置/坑 |
|---|---|---|
| 自动识别行列与参数 | 自动推断内角点行列、单格尺寸、DPI | 需先导入棋盘格图；识别中按钮临时禁用 |
| 导入棋盘格图像 | 选择棋盘格扫描图（系统对话框） | 记住上次目录；与相纸同目录时看清文件名 |
| 检测角点并校验 | 检测角点→拟合→残差校验，产出精度预估 | 需已导入图；失败会红字提示尝试切换识别模式 |
| 保存标定参数 | 保存校准 npz（只读产物） | 仅在「校验通过」后可用 |
| 高级参数（点击展开/收起） | 展开膨胀/实测尺寸/分区校正/阶数/算法/亚像素 | 日常不用动；默认收起 |

## 4. 阵列页（②③）

| 按钮 | 行为 | 前置/坑 |
|---|---|---|
| 阵列规格下拉 | 选 5×5 等预设，联动行/列 | 与手动改行列会互相同步 |
| 自动建系（全内角点） | 全内角点最小二乘建系 | **必须先完成标定**，否则提示且不执行 |
| 删除上一个点 | 手动建系时回退一个点，可连续回退 | 仅手动建系过程可用 |
| 全部重置 | 清空三点重新开始 | 会丢失当前点选 |
| > 检测设置（点击展开） | 阈值模式/极性/搜索窗口/整图处理/中心算法 | 默认收起；改完直接生效 |
| > 点选参考点（点击展开） | 展开手动建系区 | 默认收起 |
| 应用阵列（下一步） | 校验并进入检测导出页 | 需已定义阵列；无建系也可先定义 |

## 5. 检测导出页（④）

| 按钮 | 行为 | 前置/坑 |
|---|---|---|
| 一键检测 | 开始十字检测（后台线程，带进度） | 未标定时**灰**；已检出点数量决定后续按钮可用性 |
| 刚体精化基准（检测后） | SVD 3DOF 精化方向轴 | 检测后可用；无改善会回滚并告警（红线 6） |
| 微调模式（拖拽） | 图上拖点微调（模式开关，可勾选） | 需已检测 |
| 手动识别（点击/精修） | 图上点选补点/修正 | 需已检测；点选范围=精化窗口半宽 |
| 清除手动点 | 撤销全部手动修正 | **红框危险按钮**；不可撤销 |
| 保存测量图片比对结果 | 逐点裁剪原图+标注，导出 PNG | 需图+结果+网格齐备；需选目录 |
| 导出整图痕迹图 | 2 倍渲染当前视图（编号+色标） | 需图+结果+网格 |
| **导出 Excel** | 导出报表（结果表+参数记录） | 检测后自动启用；等价 Ctrl+E |

## 7. 弹窗按钮

**多摆放系统残差校正**：导入第 N 张（×5）/ 导入棋盘格数据文件（跳过检测）/ 开始拟合与验证（≥3 个摆放后可用）/ 保存残差层并加载到界面 / 关闭。
**列设置**：默认 8 列 / 全部列 / 最少列 / 全选 / 全不选 / 确定 / 取消。
**关于**：打开日志目录 / 复制版本信息 / 确定。
