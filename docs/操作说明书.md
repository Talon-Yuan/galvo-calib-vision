# GalvoCalibVision 操作说明书（v4.0 / 2026-10-27）

> 面向现场操作员。四步流程：1 标定棋盘格 -> 2 导入相纸扫描图 -> 3 定义阵列与建系 -> 4 检测与导出。
> 界面内「帮助 -> 使用说明（F1）」内置同一份双语手册。

## 0. 启动与准备

1. 双击 GalvoCalibVision.exe（免安装，整个目录拷贝即可）。
2. 确认扫描仪 4800dpi、相纸无折痕。
3. 启动异常：看 logs\crash_*.txt 与 logs\app_*.log。

## 1. 标定棋盘格（必需前置）

1. 左栏「1 标定棋盘格」->「导入棋盘格图像」-> 选棋盘格图。
2. 点「自动识别行列与参数」（也可手填内角点行/列、单格尺寸、DPI）。
3. 点「检测角点并校验」，等「精度预估」出现绿色「达标判定」。
4. 点「保存标定参数」-> 生成 npz。
5. 右上「校准前置」徽标变为「已通过」。

判读：校准 RMS <=0.05mm 才合格；膨胀/分区/阶数/算法在「高级参数（点击展开）」内，日常不用动。

## 2. 导入相纸扫描图

- 点顶部流程条第 2 步「2 导入相纸扫描图」直接弹导入；或 文件 -> 导入扫描图（Ctrl+O）。
- 超大图后台加载；载入后预览出现图像、占位提示消失。
- 易错：对话框记住上次目录；标定图与相纸常在同一文件夹，看清文件名再确认。误选标定图时日志与状态栏会提示「同一张图」。

## 3. 定义阵列与建系

1. 「阵列规格」下拉选 5x5（与行/列联动），填设计间距（如 30.000mm）、扫描 DPI。
2. 建系二选一：
   - 自动：「自动建系（全内角点）」——需已标定；
   - 手动：「点选参考点（点击展开）」-> 依次点 原点 / X 向第二点 / Y 向第二点，点完自动进入下一个。
3. 点错用「删除上一个点」可连续回退；「全部重置」清空。
4. 底部「本步操作」->「应用阵列（下一步）」进入检测页。
- 红线：间距必须填设计值，不得填实测值。

## 4. 检测与导出

1. 点「一键检测」（未标定时为灰、不可点）。
2. 结果表默认 8 列：序号/行/列/物理X/物理Y/偏差/判定/状态（工具 -> 列设置可增减）。
3. 异常点用「手动识别（点击/精修）」修正；「清除手动点」撤销。
4. 点「导出 Excel」（检测与导出页主按钮）或 Ctrl+E；也可保存比对图、导出痕迹图。
5. 判定看顶部汇总条与报表判定列：RMS <=0.15mm、Max <=0.40mm 达标。

## 5. 多摆放系统残差校正（高级）

1. 工具 -> 多摆放系统残差校正。
2. 依次导入 5 种摆放（0 / +-5 / +-10 度），每张显示「已导入」徽章与检测点数。
3. >=3 个摆放后点「开始拟合与验证」，看 LOO-RMS（越小越可信，建议 <=0.03mm）。
4. 点「保存残差层并加载到界面」。
- 残差层与幅面指纹绑定，禁止跨幅复用。

## 6. 主题与语言

- 工具 -> 深色模式（勾选，记忆选择）。
- 右上角「语言：中文/English」切换，菜单、左栏、弹窗、手册同步。

## 7. 常见问题速查

| 现象 | 处理 |
|---|---|
| 一键检测灰/没反应 | 未完成标定（标定为前置），看右上「校准前置」 |
| 导入后预览空白 | 大图仍在后台加载，等状态栏；看日志 |
| 切英文后个别中文 | 反馈（当前 4 条为「中文/English/NG」应有原样） |
| 结果全 NG | 核间距是否为设计值、标定是否通过、建系方向是否点反 |
| 网格自动校正达上限 | 设计上限 3 轮后放弃；建议重选方向点或核间距 |
| 深色下文件框是浅色 | 系统原生对话框限制，已知 |

## 8. 快捷键

Ctrl+O 导入 · Ctrl+E 导出 Excel · Ctrl+S 保存工程 · F1 使用说明


## 9. 本版行为变化（v4.0，操作员必读）

1. **改阵列参数会清空旧检测结果**：检测后若改行/列/间距/DPI/含中心点，
   网格与结果自动清空并提示"请重新建系并检测"（防止报表用新参数解释旧坐标）。
2. **重置点选后不能直接导出**：导出按钮变灰，需重新建系；点导出会提示"阵列未定义"。
3. **先标定也看得到绿十字**：未导入相纸时，标定页识别的角点绿十字与识别范围红框正常显示。
4. **深色模式记忆**：切深色后关闭再开仍是深色。
5. **导出 Excel 入口**：检测后在「④ 检测与导出」页顶部有主按钮（另有 文件→导出 Excel / Ctrl+E）。
6. **误选同一张图会提示**：相纸与标定棋盘格是同一文件时，日志与状态栏给出警告。
7. **换图会清掉旧状态**：导入新图后旧网格、旧结果、旧锚点、手动模式全部重置。
