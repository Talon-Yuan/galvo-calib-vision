一、本版主题
1) 新增"辅助建系"：点一下阵列中心 → 软件扫描精测 → 按参数建坐标系 → 检测
2) NG 判定改为"名义值 vs 实际值之差"（不再把整板平移吸收掉）
3) 坐标轴方向规定：原点右侧 +X、原点上方 +Y（物理 Y 向上为正）

二、辅助建系（新增点选模式下拉）
- 单点 · 阵列中心（默认）：点中心附近任一十字 → 局部扫描亚像素精测中心 → 邻域估方向
- 单点 · 起始角点：点角上十字 → 精测该角点 → 按参数向阵列内侧铺网格
- 两点 · 中心 + X 方向：第二点约束 X 轴（阵列稀疏/旋转时更稳）
- 三点 · 原点 + X + Y：沿用旧行为
- 远点保护：点击离最近十字 >1.5×间距 / 精测锚点偏移 >1×间距 / 邻居<2 → 明确提示，不建假网格
- 偶数列/偶数行：中心由相邻十字中点推算；不足时 ±半格并告警

三、NG 判定与坐标轴（语义变更，老报表请重测）
- 判定坐标：以判定原点（精测中心/角点）为 (0,0)，**不再减"实测拟合中心"**
- 偏差 = 实测 − 名义；NG 判据：|ΔX|>公差 或 |ΔY|>公差（默认 ±0.05mm，模板可覆盖）
- 物理 Y 向上为正：表内 Y/ΔY 符号与旧版相反；整板平移会真实反映为同号同量级偏差
- 名义原点：中心模式 (0,0) 在阵列中心；角点模式 (0,0) 在起始角点；加载模板时以模板值为准
- Excel 列名/列结构不变（红线 9），仅数值语义变化；参数页新增"判定原点/坐标轴"
